# 센티넬·가이드 통합관리국 — 매칭 적합성 검사 (개인용)

자캐 페어의 서사·성향을 입력하면 **매칭 적합률·역할(센티넬/가이드)·능력 등급·보직·캐해**를
공문서 스타일 **판정서**로 뽑아 주는 로컬 앱. 결과는 이미지로 저장할 수 있다.

배포용이 아니라 **내 컴퓨터에서 혼자 쓰는 용도**로 만들어졌다.

## 구성
- `index.html` — 앱 본체 (입력 폼 · 판정서 · 이미지 저장). 그 자체로 동작한다.
- `server.mjs` — 로컬 Node 서버(의존성 0). `/judge` 요청이 오면 `claude -p`를
  `child_process`로 실행해 **캐해 소견을 AI가 작성**한다. **구독 인증 사용, API 키 불필요.**

## 두 가지 사용법

### 1) 그냥 열기 (AI 없이, 선택지 기반 판정)
`index.html` 을 브라우저로 더블클릭해서 열면 끝.
- 선택지 기반 **결정론 판정**이 나온다(같은 입력 → 같은 결과).
- 캐해 소견은 선택지들을 엮은 문장으로 생성된다.

### 2) 로컬 서버로 열기 (AI 판정)
`claude`(Claude Code CLI)에 **로그인된 상태**에서:

```bash
node server.mjs
# → http://localhost:5173 접속
```

- 판정서를 발급하면 `server.mjs`가 입력을 모아 `claude -p "..."`를 실행하고,
  돌아온 텍스트로 **캐해 소견을 교체**한다("AI 판정" 배지 표시).
- `claude`가 없거나 실행이 실패하면 **자동으로 결정론 소견으로 폴백**한다(앱은 안 멈춘다).

### 참고
- 포트 변경: `PORT=8080 node server.mjs`
- `claude` 실행 파일 경로 지정: `CLAUDE_BIN=/path/to/claude node server.mjs`
- 프로필 붙여넣기는 인당 2,000자로 잘라 전달한다.
- 판정 로직/문항/디자인은 `index.html` 안에 모여 있어 원하는 대로 수정하면 된다.

※ 창작(자캐) 활동용이며 실제 효력은 없다.

## 깜돌의 섬 산책 (`kkamdol/index.html`)

예주니와 함니가 작은 섬을 걷는 산책 미니게임. 파일 하나로 동작하며 외부 리소스가 없다.
- 이동: 방향키 · WASD · 화면 클릭(모바일은 터치 패드)
- 행동: `E` 또는 스페이스바 — 얘기하기, 조개 줍기, 부두 끝에서 낚시
- 수첩: 잡은 물고기 5종 · 조개 3종 기록(브라우저 localStorage에 저장)
- 링크 미리보기: `kkamdol/og.jpg`(1200×630) — 카톡·X 등에 주소를 붙이면 이 이미지가 뜬다
